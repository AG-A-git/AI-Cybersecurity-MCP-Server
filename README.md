# AI-Cybersecurity-MCP-Server

An AI-powered, multilingual static code vulnerability analyzer using an MCP Server and Llama 3.

## Project Overview

This project aims to identify potential security vulnerabilities in source code. It provides a web interface for users to manage projects, upload source files, run security scans, and review results.

## Key Features

- User registration and login
- JWT-based authentication
- Security dashboard
- Project creation and management
- Source-file upload
- Scan results and vulnerability details
- Uploaded-file history
- Reports and profile pages

## Technology Stack

### Frontend
- React
- Vite
- JavaScript
- Axios
- React Router

### Backend
- Python
- FastAPI
- JWT-based authentication

### Security Analysis
- Static code vulnerability analysis
- MCP Server and Llama 3 integration, as supported by the project backend

## Application Workflow

1. Register or log in.
2. Open the dashboard.
3. Create or select a project.
4. Upload a supported source file.
5. Run the security scan.
6. Review scan results.
7. Open vulnerability details.
8. Review uploaded files
